# Version 0.8/0.7.5 Changelog:
### Bugfixes:
    - Fixed the incorrect display of the Mod dependent Recipes
    - Fixed the recipe for the Will item not appearing for the Yggdrasilsteel Armor
    - Fixed the issue where items would not drop when the Core Altar, Modifcation Altar or the Ritual Pedestal is destroyed
    - Fixed the advancements not working
    - Fixed Errors being displayed when Expanded Combat is not loaded
    - Fixed the duplication Bug on the Botanic Ritual
    - Fixed an Error where the lore of the First Relic would also be applied to other items
    - Fixed the Sound spam that would appear wehen equipping the core item
    - Fixed the chat spam that occured when not being able to fly anymore.

### Changes:
    - Increased the Required Mod dependencies to avoid more errors
    - Increased the drop-chances for the Yggdrasil Heart (3% -> 30%)
    - increased the mana capacity of the Yggdrasilsteel Band of Mana (8.000.000 -> 32.000.000)
    - The Text regarding switching to the next Relic is now translateable

### Features:
    - Introduction of the Ore Infusion Altar:
        * Converts raw materials into their smelted version by consuming mana
        * Currently supports: gold, iron, copper, ancient debris and elementium (more can be added when required)
    - Added more advancements
    - Added chinese translation(zh_cn) (thanks to karap11)
    - improved the Lexica Botania
    - Added some particles when crafting with the Botanic Ritual
